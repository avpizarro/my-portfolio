## Portfolio (this site)
**Description:** Portfolio website for displaying Alejandra's projects and experience, inspired by the Museo La Tertulia website design. It includes an AI chatbot that answers questions about her background, skills, projects, availability, and contact details.
**Tech stack:** Next.js 15, React 19, SCSS modules, Sanity CMS, Anthropic Claude API, React Markdown, Server-Sent Events, KwesForms, Lenis, and Vercel.
**Chatbot architecture:** A Next.js API route loads the Markdown files in the `data` directory as a server-side knowledge base and includes them in Claude's system prompt. Claude Haiku is instructed to answer only from that material, while responses are streamed to the browser for a responsive chat experience. The interface preserves the latest 20 messages as conversation context, supports Markdown, and adapts to mobile screens.
**Live site:** https://my-portfolio-avpizarro.vercel.app/
**GitHub:** https://github.com/avpizarro/my-portfolio
